## 二、录制方式建议

### 方式 A：Win + G（Xbox Game Bar）—— 最省事，系统自带

1. 先运行游戏（Godot 里按 **F5**），让游戏窗口在最前面。
2. 按 **`Win + G`** 呼出 Xbox Game Bar。
3. 找到**捕获（Capture）**那个小窗口（如果没看到，点顶部的「捕获」图标）。
4. 按 **`Win + Alt + R`** 开始录制，再按一次停止（也可以点那个红色圆点按钮）。
5. 录制文件默认存在：
   `C:\Users\<你的用户名>\Videos\Captures\`
   （也就是「此电脑 → 视频 → Captures」）
6. 双击就能用系统自带的「电影和电视」播放器看。

**优点**：不用装东西，快捷键一个。**缺点**：偶尔录不到窗口，或者录音质量一般。

### 方式 B：OBS Studio —— 更稳，功能全

1. 去 `obsproject.com` 下载安装（免费开源）。
2. 第一次打开会有「自动配置向导」，选 **「仅用于录制」**，按提示走完。
3. 在下方 **「来源 / Sources」** 面板点 **「+」**：
   - 加 **「游戏捕获 / Game Capture」**（录游戏窗口，最清晰）；或
   - 加 **「显示器捕获 / Display Capture」**（录整个屏幕，最保险，一定能录上）。
4. 设置 → **输出 / Output** → 输出模式选**简单** → **录像质量**选「高质量」，
   **录像格式**建议 `mp4`（方便发给别人）。
5. 设置 → **输出 → 录像路径**，改成你好找的文件夹。
6. 点右下角 **「开始录制 / Start Recording」**。

**优点**：稳、画质好、能录麦克风。**缺点**：要装、第一次配置要几分钟。

### 录制的 5 条要求（很重要）

| 要求 | 为什么 |
|---|---|
| **连续玩 5 分钟，一次到底，不许剪** | 你剪掉的那一段，恰好藏着 bug |
| **从出生点开始，玩到你能玩到的最远处** | 要覆盖完整的实际流程 |
| **死多少次都别重录** | 频繁死亡的地方就是难度问题所在 |
| **开着麦克风口述**（「这里我跳不上去」「刚才我明明按了」） | 你当下的吐槽就是最真实的 bug 报告，事后会忘 |
| **玩之前先别热身**（别先偷偷练 10 遍） | 第一遍的生疏感，和朋友的体验最接近 |

## 三、观察清单（照着一条条看）

看录像的时候，**逐条打勾**。每发现一个问题，都记到第四节的表格里。

### A. 碰撞类
- [ ] **穿模**：角色陷进平台/墙里，或者站在平台边缘「陷下去一角」。
- [ ] **穿墙**：贴墙快速移动或斜跳时，直接从墙里穿过去。
- [ ] **卡角落**：在墙角/两块平台接缝处动不了，必须重开。
- [ ] **卡在天花板**：跳到平台底下时，头卡住，落下不来或者被顶穿。
- [ ] **掉出关卡**：从关卡侧面/顶部掉出去，永远不会触发死亡区（一直往下掉）。

### B. 跳跃与手感类
- [ ] **跳不上去**：明明看着能跳到的平台，试了 3 次以上还是失败。
- [ ] **边缘跳不出来**：站在平台边缘按跳，没反应（说明土狼时间不够，或平台边缘判定有问题）。
- [ ] **按了没反应**：确定按了跳，角色没跳（跳跃缓冲的问题，或者键盘丢失输入）。
- [ ] **一次跳两下 / 多段跳**：按一下跳出了两格高度。
- [ ] **落地抖动**：站在平台上时角色在微微上下抖（物理抖动的典型症状）。
- [ ] **空中不听话**：空中想微调位置，角色完全不听（这是空中控制系数的取舍，想清楚是特性还是 bug）。
- [ ] **惯性太滑**：松开方向键之后还滑很远，导致掉下去。

### C. 死亡与复活类
- [ ] **复活位置错**：复活在检查点里面（嵌进去了）、复活在半空中、或者复活后会立刻再死一次。
- [ ] **检查点没生效**：碰过检查点之后掉下去，还是回到出生点。
- [ ] **死亡重复计数**：掉一次死亡区，死亡次数 +2 甚至更多。
- [ ] **死亡惩罚太重**：一次失误要重玩 30 秒以上（计划明确说这是劝退点）。
- [ ] **死亡区误判**：还没掉到底就被判死，或者站在安全平台上被误判死亡。

### D. 机关类（Day 8/9 之后才有，Day 7 可能还没有）
- [ ] **落在移动平台上不走 / 被甩下来**。
- [ ] **火焰判定过大**：离火焰还有一段距离就死了。
- [ ] **火焰判定过小**：碰到火焰没事。
- [ ] **闪烁平台消失前没有预警**（玩家觉得被耍）。
- [ ] **按钮踩了没反应**（没有视觉/听觉反馈）。
- [ ] **门开了但还能撞到 / 门没开却穿过去了**。

### E. 性能与稳定性
- [ ] **掉帧**：画面一顿一顿的（打开「调试 → 显示器」看 FPS 是不是掉到 30 以下）。
- [ ] **卡顿一瞬间**：每次进关卡/重开时会明显卡一下。
- [ ] **内存一直涨**（玩久了越来越卡）。
- [ ] **崩溃 / 报错**：游戏直接退出，或者编辑器「调试器」面板里出现红字。
- [ ] **运行久了才出现的问题**：比如 5 分钟后机关不同步了。

### F. 按键与输入
- [ ] **按键没反应**：某个方向或跳跃偶尔失灵。
- [ ] **按一下触发多次**（比如按一次 R 重开了两次）。
- [ ] **`R` 重开不干净**：重开后门还是开的、检查点还是亮的、死亡次数没按预期处理。
- [ ] **`Esc` 退出/暂停行为不一致**（有时退出、有时暂停）。

### G. 画面与可读性（不用修，先记下来）
- [ ] **看不清危险物**：火焰和平台颜色太接近，第一眼分不出哪个能踩。
- [ ] **看不清玩家**：角色太小、颜色和背景混在一起。
- [ ] **镜头问题**：镜头跟不上角色、角色跑出屏幕边缘、镜头抖。
- [ ] **不知道往哪走**：场景里没有一个明确的「往上/往前」的视觉引导。

### H. 最主观但最重要的一条
- [ ] **哪一刻你最想关掉游戏？** 把时间点（录像第几分几秒）记下来，那一段就是最该改的地方。

## 四、问题分级标准（P0 / P1 / P2）

发现问题之后，**每个问题都必须分一个级**。分级决定了它今天修不修。

| 级别 | 定义 | 典型例子 | 今天怎么处理 |
|---|---|---|---|
| **P0 · 卡关，必须修** | **玩不下去了**：卡死、必死循环、操作完全失效、崩溃 | 卡在墙角动不了；跳不上去导致过不去；复活在死亡区里反复死；按 R 无法重开；游戏崩溃 | **今天必须修完并复测通过** |
| **P1 · 影响体验，先记着** | 能玩完，但很难受、很别扭、很气人 | 跳得很勉强（要试 5 次才过）；复活点太远；火焰看不清；平台带人不太稳；死亡惩罚偏重 | **只记录，留到 Day 13 一起修** |
| **P2 · 以后再说** | 不影响通关，也不影响心情 | 颜色不好看；标题字号小；音效有点小；跳跃音不够脆；没有粒子 | **只记录，做完 14 天再说** |

### 分级时的 3 条规矩
1. **拿不准的一律往高一级放**（犹豫 P0 还是 P1 → 先当 P0 处理，看一眼）。
2. **「我玩得很熟所以能过」不算通过** —— 判断标准是「**第一次玩的人**能不能过」。
3. **同一个问题只记一条**，别拆成五条刷数量。分级看的是**影响**，不是**数量**。

### 今天动手的边界（写给自己看）
- ✅ **允许**：改数值（重力、速度、土狼时间、缓冲、平台位置、检查点位置）、修碰撞形状尺寸、修信号连接、修复活逻辑。
- ❌ **禁止**：加新节点类型当玩法（火焰/门/移动平台）、加新关卡、换美术、重写玩家控制器、改项目结构。
- 如果某个 P0 的修法**必须新增功能** → 那就不是一个能今天修的 P0，
  说明它是**设计问题**：用「挪平台 / 加宽平台 / 挪检查点」这类**改布局**的方式绕开它。
