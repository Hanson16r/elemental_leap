## 1. 六个新机制

### 1.1 金币（收集 / 分数）

- **规则**：每关 5 枚；普通金币 +1；不强制全拿；通关界面显示“金币 4/5”。
- **作用**：分数 + 鼓励走支路。**不做"金币不够不能过关"**，避免卡关。
- **位置原则**：3 枚在主路，2 枚在支路/危险处；支路的金币是"迂回"的奖励。
- **保存**：每关记录最好金币数，关卡选择卡片上显示小金币图标。
- **实现**：`coin.tscn`（Area2D + 旋转/上下浮动），碰了消失、计数 +1、播一声。

### 1.2 敌人（两种）

| 敌人 | 行为 | 玩家怎么应对 | 出现位置 |
|---|---|---|---|
| **史莱姆（巡逻）** | 在平台上左右走，到边/墙掉头，速度 60 | 跳过 / 等它走远 | 平地、宽平台 |
| **冰蝠（飞行）** | 上下/正弦移动，速度 40 | 等它让开 / 从下方穿过 | 竖井、风场附近 |

- **规则**：碰到就死（和火焰一致）；**先不做踩踏**，降低实现和调试成本。
- **公平性**：敌人不出现在"必须精确跳"的边缘 80 像素内；不做"看不见的敌人"；
  死亡后敌人复位。
- **实现**：`enemy_walker.gd`（固定 patrol 范围，掉头）、`enemy_flyer.gd`（正弦），
  都是 Area2D + `body_entered` → `player.die()`。
- **可选（加分）**：踩头顶击败敌人 + 掉 1 金币；这是 10 天版的 stretch，不排进 Must。

### 1.3 间歇火焰（地火 / 天火）

- **地火**：地面喷口，周期性向上喷火柱；**天火**：天花板向下喷。
- **节奏**：灭 2.0 秒 → 预警 0.4 秒（喷口发光/闪烁）→ 着火 1.0 秒 → 循环。
- **规则**：只有"着火"阶段碰到才死；预警阶段可以过，但要快。
- **位置**：地火放在可走地面（和以前的"火焰只在坑底"不同，这次是**节奏机关**）；
  天火放在天花板，玩家从下方经过。
- **实现**：`flame_jet.gd`（Area2D + Timer + 视觉状态），`direction` 上下；
  预警时改颜色，着火时开 `monitoring` 并拉长火焰视觉。
- **设计红线**：每个喷口旁边必须有一个"安全等待位"；不能两个喷口同时覆盖唯一通路。

### 1.4 滑冰（水结冰 + 低摩擦）

- **规则**：水池被冰冻成桥后，桥面是**滑的**：玩家在地面上的加速/减速变低
  （例如只有正常的 15%），会带着惯性滑出去。
- **风险**：滑得太快会冲出桥面掉下去；需要提前松手/起跳/用墙刹住。
- **两种用法**：
  - **危险桥**：桥不长，但尽头是坑，滑过头就掉下去；
  - **滑道捷径**：一条长冰滑道，速度快，能跨过普通跳不过的坑，但落点很窄。
- **实现**：冰桥的平台带 `is_slippery() = true`；玩家 `_physics_process` 里
  检测脚下碰撞体，滑的话把 `ground_accel_mult` 乘 0.15。
- **视觉**：冰面更亮、带反光；最好有一条"滑"的提示线。

### 1.5 移动平台 + 风场

- **组合 1：风场升降台**——竖井里有一块上下移动的平台，平台外面是风场。
  站平台是安全路线；掉下去会被风托一下，给一次补救机会。
- **组合 2：横风渡船**——横向移动平台穿过风区；玩家在平台上时，
  风只影响"跳出去之后"的速度，不影响平台本身。
- **规则**：平台和风场都用现成的 `moving_platform.gd` / `wind_field.gd`，
  只做关卡摆放，不写新物理。
- **风险**：移动平台 + 风场 + 敌人同屏时容易乱；**一个屏幕内最多两个活动机关**。

### 1.6 钥匙 + 门（迂回的关键）

- **规则**：钥匙是"一次性拾取"，不进元素槽（玩家可以同时拿钥匙 + 一个元素）；
  拾取后 HUD 显示钥匙图标；**钥匙门**需要钥匙才开。
- **用法**：
  - **可选**：钥匙在支路，门后是"金币房/捷径"，不开也能通关；
  - **必需**：钥匙在主路尽头，门在另一条路——逼玩家走一个"环"。
- **推荐**：先做**可选**，避免"没拿钥匙卡死"；必需钥匙放到第 13 关再试。
- **实现**：`key.tscn`（Area2D），`player.has_key`；`locked_door.gd` 检查
  `player.has_key`，有钥匙才开；HUD 显示钥匙。

## 2. 四种"迂回"结构

不要每关都是一条直线。用下面四种模板：

### 2.1 Y 型分叉

```
        ┌─ 上层：冰滑道（快、危险）── 金币×3 ──┐
起点 ───┤                                      ├─ 汇合 ── 终点
        └─ 下层：史莱姆（慢、安全）── 金币×2 ──┘
```

- 两条路都通终点；上层是"高风险高金币"，下层是"稳"。
- 汇合点之后不要再分叉，避免迷路。

### 2.2 环型回廊

```
起点 ── 房间 A（拿冰种）── 单向落下 ── 房间 B（水池）
  ▲                                      │
  └──────────── 回到 A 的捷径 ────────────┘
```

- 玩家在 A 拿元素，去 B 用，再从 B 回到 A；空间上是一个环。
- 适合"先拿元素、再回来用"的解谜。

### 2.3 上下双层

```
上层：风场 / 金币 / 钥匙
  ▲ 风场竖井        ▼ 落口
下层：地火 / 史莱姆 / 主路
```

- 上层快但危险，下层稳但有敌人/火焰；玩家可以在竖井处切换。
- 适合"移动平台 + 风场 + 间歇火焰"同屏。

### 2.4 钥匙-门 + 金币房

```
主路 ── 分岔 ── 支路（钥匙）── 锁门 ── 金币房（2 金币）
   └──────────── 主路继续 ────────────── 终点
```

- 钥匙在支路，门后是奖励；不拿钥匙也能通关。
- 先做可选，避免卡死。

## 3. 四个新关卡

### 第 10 关 ·「分岔」（Y 型 + 金币 + 敌人 + 滑冰）

- **目标**：第一次让玩家"选路"。
- **结构**：Y 型分叉；上层冰滑道（3 金币），下层史莱姆巡逻（2 金币）。
- **元素**：冰（冻桥/滑道）+ 火（终点门）。
- **流程**：
  1. 起点拿冰种，冻住分岔口的水池；
  2. 上层：冰滑道，滑到尽头要跳，否则掉坑；3 金币；
  3. 下层：两只史莱姆，安全但慢；2 金币；
  4. 汇合 → 火种 → 火盆门 → 终点。
- **迂回点**：上层快但滑、下层稳但躲敌人；金币是奖励，不强制。
- **时长**：60 秒；检查点 1 个（汇合点）。
- **验收**：两条路都能到终点；上层能滑、能跳；下层敌人能躲。

### 第 11 关 ·「风车」（移动平台 + 风场 + 上下双层）

- **目标**：把"移动平台"和"风场"组合起来。
- **结构**：上下双层；中间一个风场竖井，竖井里有一块上下移动的平台。
- **流程**：
  1. 下层：地火喷口（间歇）+ 史莱姆；
  2. 站上风场里的升降台，被带到上层；
  3. 上层：金币 + 钥匙（可选），钥匙开金币房门；
  4. 从上层落口回到下层，火盆门 → 终点。
- **迂回点**：上层钥匙/金币房是可选；下层主路更稳。
- **时长**：70 秒；检查点 1 个（竖井底）。
- **验收**：升降台能站、能上下；风场能托人；地火有安全等待位。

### 第 12 关 ·「火雨」（间歇火焰 + 敌人 + 环型回廊）

- **目标**：节奏关；读火焰的"灭-预警-着火"。
- **结构**：一个环型房间；天花板天火 + 地面地火交替；史莱姆在环上巡逻。
- **流程**：
  1. 进入环形房间，先看一轮火焰节奏；
  2. 沿环走，等天火灭了过；地火灭了再过；
  3. 环上有 2 个金币；中间有一个钥匙（可选）；
  4. 出口火盆门 → 终点。
- **迂回点**：环的两个方向都能走，一边敌人多、一边火焰多。
- **时长**：70 秒；检查点 1 个（环入口）。
- **验收**：火焰节奏可读；不会两个喷口同时封死唯一通路。

### 第 13 关 ·「冰宫」（综合 + 滑冰 + 钥匙 + 五元素）

- **目标**：10 天版的收尾关，把滑冰、钥匙、元素、敌人全放进来。
- **结构**：冰宫三层；滑道 + 风场 + 间歇火焰；钥匙在支路，锁门后是金币房。
- **流程**：冰种冻滑道 → 滑过第一层 → 风场到第二层 → 火融冰墙 →
  钥匙（支路）→ 锁门 → 金币房 → 第三层 → 终点。
- **时长**：90 秒；检查点 2 个。
- **注意**：这一关是 **stretch**，10/29 还没做完就砍掉。
