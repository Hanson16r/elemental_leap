## 三、封面图构图文案

### 尺寸建议

| 尺寸 | 用在哪 | 备注 |
|---|---|---|
| **630 × 500** | **itch.io 的项目封面（Cover Image）** | 官方推荐尺寸；注意 itch 在不同位置会**裁切**成不同比例 |
| **1200 × 630** | 微信/朋友圈/微博/Twitter 分享时的大图 | 大概是 1.9:1，横向铺开 |
| 1920 × 1080（可选） | itch.io 项目页里的**截图** | 直接在游戏里截图更好，别用封面替代截图 |

**安全区提醒**：itch.io 会把封面裁成正方形、长方形等各种比例。
所以**标题和角色这些关键元素，全部放进画面中间 80% 的区域**，四周留出会被裁掉的余地。

### 画面里画什么（推荐构图）

```
┌──────────────────────────────────────────────┐
│  深蓝夜空 + 细雪粒子（半透明白点）              │
│                                              │
│        ✦  ✦            ✦                     │
│                                              │
│   ▬▬▬▬▬▬▬        ← 悬浮冰台（冰蓝渐变矩形）    │
│            ▬▬▬▬▬▬▬                           │
│   ▬▬▬▬                ▬▬▬▬▬▬▬▬▬             │
│          ▲▲▲          ← 蓝色火焰（三角形）     │
│                🟦      ← 主角小方块（亮青色）  │
│   ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬             │
│                                              │
│         冰 塔 跳 跃                           │
│         I C E   T O W E R   J U M P          │
│         3 关 · 大概 5 分钟能通关               │
└──────────────────────────────────────────────┘
```

**元素清单（从下往上画）**
1. **最底下一排「冰台剪影」**：3–5 个长短不一的浅蓝矩形，做出「一路往上」的上升感（右下角最低、左上角最高）。
2. **主角**：一个亮青色（`#7FD8FF`）的小方块或圆角方块，带一点**浅蓝描边**和一点**发光**（外发光）—— 它是画面唯一的高饱和亮点，视线自然被吸过去。
3. **蓝色火焰**：1–2 个**三角形或火焰形**的深蓝到亮青渐变，放在主角旁边，制造「危险就在眼前」的紧张感。**不要用红色/橙色**，会破坏冰雪配色。
4. **雪雾粒子**：撒 30–60 个半透明白点，大小不一，**越往画面下方越少**（近处的雪更清楚）。
5. **背景**：从上到下做**深蓝 → 蓝紫**的竖向渐变，营造「塔很高」的感觉，可加 1–2 道斜向的浅色光带。

**标题放哪**
- 位置：**画面下方 1/4 处，水平居中**（标题压在最下面的冰台上也可以，更有代入感）。
- 中文主标题「**冰塔跳跃**」：**最大号、加粗**，字高约占画面高度的 **1/6**，纯白 `#FFFFFF` + **深蓝描边/投影**（保证在亮背景上也看得清）。
- 英文副标题「**ICE TOWER JUMP**」：主标题下方，字号约为主标题的 **1/4**，**字间距拉大**，浅蓝 `#BFE9FF`。
- 一行卖点小字：「**3 关 · 大概 5 分钟能通关**」或「**浏览器直接玩**」，放在最下方，字号最小，半透明白。

**配色建议（冰雪蓝白，直接用这些色值）**

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景深色 | `#0B1B33` | 深蓝夜空，压住整张图 |
| 背景亮色 / 渐变下端 | `#1B3B66` | 和深蓝做竖向渐变 |
| 冰台主色 | `#4FC3F7` | 标准冰蓝 |
| 冰台高光 | `#BFE9FF` | 冰台顶面一道亮边，立刻有「冰」的质感 |
| 主角色 | `#7FD8FF` | 比冰台更亮，最抓眼 |
| 危险物（火焰） | `#2A6DD9` → `#7FD8FF` 渐变 | 深蓝到亮青，冷色系危险物，和项目里的蓝色火焰一致 |
| 文字 | `#FFFFFF` / `#EAF6FF` | 白 + 极浅蓝 |
| 强调/点缀 | `#A7F3FF` | 只在主角高光和标题描边上用一点点 |

**配色红线**：整张图**不要出现红、橙、黄**（除了非常小的星星点缀），
**冷暖对比只有一处** —— 就是主角的亮青色。一处对比比十处对比好看得多。

### 怎么把封面图做出来（零基础做法）
1. 先在**游戏里截图**：运行游戏（F5），走到一个「平台 + 火焰 + 主角」都在画面里的位置，按 `Win + Shift + S` 截取一块区域，存成 png。
2. 打开 **PowerPoint**（或 Canva / Photopea / 画图3D）新建一个 **630 × 500** 的页面，把截图铺满。
3. 在截图上叠一层**半透明深蓝矩形**（透明度 30%–50%），让后面的标题能看清。
4. 加上标题、副标题、卖点小字。字体选**黑体类粗体**（微软雅黑 Bold / 思源黑体 Bold 都行）。
5. 导出为 **PNG**（不要 JPG，标题边缘会有杂边）。
6. 再复制一份，把画布改成 **1200 × 630**，重新摆一遍位置，导出第二张给社交平台用。

> **偷懒方案**：只做 1 张 630 × 500 也能发布 —— 但**至少要有 2 张游戏内截图**放在 itch.io 页面上，
> 因为很多人是看截图决定要不要玩的。
