# 冰塔跳跃 · 12 关设计思路（最新版）

> 2026-10-29 按当前代码的实际布局整理。本文只描述这一版“是什么、为什么”，
> 不再保留历史改号过程；旧《关卡设计思路》里的 14 关编号、第 4 关「冰之谷」、

## 0. 一页看完

- 12 关，2D 平台跳跃 + 元素解谜；每关一个主题，最后两关综合。
- 顺序：绿色平原 → 火雨 → 火之花 → 风之丘 → 岩石矿洞 → 水之洞 → 元素回廊 →
  天空之城 → 分岔 → 风车 → 冰宫 → 终章：元素城堡。
- 难度曲线：1 基础 → 2 节奏 → 3 火 → 4 风 → 5 岩 → 6 火/冰 → 7 四元素 →
  8 风场回字 → 9 选路 → 10 平台/风 → 11 冰宫 → 12 综合。
- 金币合计 58 枚；除第 8 关外每关都有检查点（第 11 关有两个）。
- 游戏里没有“受伤”和“攻击”：掉下去、碰火、横向撞怪都是即死；唯一的主动交互是“从上方踩史莱姆”。

## 1. 核心规则

### 1.1 操作

- A / D 左右移动，空格跳（短按小跳、长按大跳），R 重开，ESC 暂停。
- 没有攻击键：敌人靠跳、躲、踩（压扁）处理，不靠打。

### 1.2 死亡与复活

- 掉进死亡区、碰到火焰/火球、横向撞到史莱姆，立即死亡，没有血量。
- 死亡后约 0.55 秒回到最近检查点；整关机关复位：
  元素球/钥匙/金币回到地图、冰桥变回水、冰墙/石墙恢复、石柱缩回、
  火盆/按钮/门关闭、移动平台回起点、火焰/敌人复位、空中的火球清掉。
- 玩家手里的元素和钥匙清空；检查点本身保留。
- 金币是例外：检查点之前吃掉的保留，检查点之后吃掉的回滚（见 1.4）。

### 1.3 史莱姆（压扁弹跳）

- 巡逻史莱姆：在出生点 ±patrol 内来回走，到边界掉头，速度 55~60。
- 喷火史莱姆：站桩，每 2.2 秒朝固定方向喷一颗火球；喷前 0.35 秒身体变红预警。
- 从上方踩中：史莱姆压扁成原高度的 22% 薄片，玩家以 0.7 倍跳力弹起
  （-480 × 0.7 = -336，弹高约 45 像素）。
- 压扁持续 0.8 秒；期间史莱姆不巡逻/不喷火、碰撞关闭；玩家离开 20 像素后才弹回原状。
- 横向撞到：玩家死；从下方顶到按横向算；史莱姆不会被踩死。

### 1.4 金币与检查点

| 情况 | 复活后 |
|---|---|
| 检查点之前吃掉的金币 | 数量保留，地图上保持消失 |
| 检查点之后吃掉的金币 | 数量退回，金币重新出现 |
| 还没碰过检查点就死 | 归 0，全部重新出现 |
| 之后又碰到新检查点 | 快照更新为那一刻的进度 |

- 金币不是通关条件，只影响结算和关卡选择的 ★（拿满本关全部金币）。
- 每关金币数不同：第 1 关 5、第 2 关 3、第 3~7 关各 5、第 8 关 6、第 9 关 4、第 10~12 关各 5。

### 1.5 终点与存档

- 碰到终点旗 → 结算（时间 / 死亡 / 金币）→ 解锁下一关。
- 共 12 关，存档版本 3；旧存档（v1 / v2）读入时按新关号自动迁移。

## 5. 逐关

### 第 1 关 · 绿色平原

- **想教**：基础操作闭环——跳坑、吃金币、踩/躲史莱姆、等移动平台、拿钥匙开门。
- **结构**：
  - A 出生：-100~400（顶 780），提示牌 260。
  - B 两坑：520~900、1020~1700；坑 400~520 与 900~1020 各 120，坑上方金币 460 / 960（y 710）。
  - C 史莱姆：x=1280，巡逻 ±60（1160~1340），金币 1250；检查点 1560。
  - D 大坑：1700~2100（400），移动平台中心 1900、宽 130、行程 ±120、速度 70。
  - E 出口：2100~3200；钥匙 2300、门 2600、终点 2800、门后金币 2700。
- **数据**：金币 5；怪 1；检查点 1；死亡区 -200~3300。
- **为什么**：合并后没有独立的“平台教学关”，一关内必须走完“跑 → 跳 → 等 → 拿钥匙”；
  平台速度只有 70，第一次见移动平台不要求精准跳。
- **验收**：5 枚金币都能拿到；检查点后死亡不用重跑前 1560；建议 3 次死亡内通关。

### 第 2 关 · 火雨

- **想教**：地火读节奏、压力板触发天火、低顶走廊不能跳、下行拿钥匙再上行。
- **结构**：
  - 入口 100~450（顶 780）；地火 380：灭 2.6 → 预警 0.4 → 着火 1.0（周期 4.0）。
  - 低顶走廊 450~800：地面 780、顶底 650，净空 130；压力板 550~700；
    天火 700（长 130）：踩板后 0.9 秒着火、烧 1.5 秒、离开 3 秒后重置。
  - 下行：800~980（顶 900）→ 960~1100（顶 1010）。
  - 最低点 900~1300（顶 1200）：史莱姆 980~1100、钥匙 1210、检查点 1240。
  - 上行 5 级：1300~1450（1130）、1490~1640（1060）、1680~1830（990）、
    1870~2020（920）、2060~2210（850）；第 4 级左缘地火 1905。
  - 高处 2250~2450（顶 780）：钥匙门 2350、终点 2420。
- **数据**：金币 3；怪 1；检查点 1；死亡区 -200~2550。
- **为什么**：倒 V 把“唯一钥匙”放在最低点，避免玩家爬到出口才发现漏拿；
  地火教“等”，天火教“踩板后 0.9 秒内冲过去，或退回来等它烧完”；
  低顶把“跳”这个万能解拿掉，逼玩家用走位和时机。
- **注意**：工具会为 130 净空报 WARN（低于 189 红线），这是本关刻意设计，不是 bug。
- **验收**：钥匙必拿；两处地火都能等到窗口；天火能躲；5 级阶梯不撞头。

### 第 3 关 · 火之花

- **想教**：火的两用——融冰墙、点火盆；两枚火种各用一次。
- **结构**：-100~600 → 700~1400 → 1500~2600（两个 100 坑）；
  火种① 300；冰墙 800；地火 1200（周期 2.9）；火种② 1550；
  火盆 1800；门 2000；检查点 1000；史莱姆 900 / 1600；金币 5；终点 2600。
- **为什么**：第一枚火种必被冰墙吃掉，第二枚专门点火盆——让玩家理解“元素是消耗品”，
  不能一枚火走天下。
- **验收**：融墙、闪地火、点火盆、开门。

### 第 4 关 · 风之丘

- **想教**：移动平台、风区加速跳远、火融冰墙。
- **结构**：-100~500 → 800~1200 → 1330~2000 → 2300~2800；
  500~800 与 2000~2300 两个 300 坑用移动平台（宽 160、行程 ±120、速度 80）；
  1200~1330 的 130 坑前有风区 1160（80 × 160，430 / 0.9 秒）；
  火种 1400、冰墙 1600；钥匙 2100、门 2500；检查点 900；
  史莱姆 1500 / 2400；金币 5；终点 2800。
- **为什么**：三种过坑方式同关对比——等平台（300）、借风（130）、硬跳（100 小坑）；
  风区做成一次性加速而不是持续推力，玩家好预判。
- **验收**：两个移动平台都能坐；130 坑能借风跳过；火墙钥匙门能过。

### 第 5 关 · 岩石矿洞

- **想教**：岩石两用——砸墙、顶石柱。
- **结构**：-100~600 → 700~1300 → 1400~2200 → 2300~2800（三个 100 坑）；
  岩石 300；石墙 900；石柱 1500（宽 180、升高 60）；钥匙 2000、门 2400；
  检查点 1000；史莱姆 800 / 1700；金币 5；终点 2800。
- **为什么**：同一枚岩石元素，既能“破坏”（砸墙）又能“造路”（升柱）；
  石柱不是必经，是给玩家试机制的安全玩具。
- **验收**：砸墙、升柱、钥匙门。

### 第 6 关 · 水之洞

- **想教**：带火融冰墙、拿钥匙开门；跳过 100 小坑。
- **结构**：-100~700 → 800~1400 → 1500~2200 → 2300~2800（三个 100 坑）；
  火种 400；冰墙 1100；钥匙 1600、门 2000；检查点 1000；
  史莱姆 1200 / 1900；金币 5；终点 2800。
- **为什么**：冰墙卡在唯一走廊上，必须先拿火；钥匙门在冰墙后，
  形成“火 → 冰墙 → 钥匙 → 门”的短链。
- **名称与实现（重要）**：关卡名和脚本头注释仍写“水会浇灭火种 / 跳过水幕”，
  但当前版本**没有放水幕**（water_zone 机制存在，关卡未调用），旧文档里的“水幕 800”从未落地。
  原因很实际：本关只有一枚火种，火在冰墙前被水浇灭就没有第二次机会，会软锁。
  要做“水”，需要在水后补第二枚火种，或把水改成“只挡路、不灭火”。
- **验收**：融墙、钥匙门。

### 第 7 关 · 元素回廊

- **想教**：冰、岩、火、风各一次，顺序明确。
- **结构**：-100~600 → 500~1000 → 1100~1600 → 1700~2400 → 2500~3000；
  冰种 250 + 冻池 600（宽 200，冰桥 500~700，与地面同高）；
  岩石 800 + 石墙 1000；火种 1200 + 冰墙 1400；风区 1600；
  钥匙 1900、门 2600；检查点 1200；史莱姆 1100 / 2000；金币 5；终点 3000。
- **为什么**：把前四关的单元素串成一条链；每个机制之间留 100~200 缓冲，不叠题；
  冻池和风区是可选体验，不卡关。
- **验收**：四种元素都用上；冰桥能冻；风区能过 100 缺口。

### 第 8 关 · 天空之城

- **想教**：两段风场 + 横跳、弱风口、周期风门、逆风走廊、升降台、回字路线。
- **结构**：
  - 起点平台 -100~940（顶 1500）；隔板 x 900~940、y 1050~1500，把终点一侧隔开。
  - 风场① 550~680（y 1000~1450，升力 260）→ 100 缺口 → 风场② 780~940（y 820~1050）；
    缺口下方 680~780（顶 1100）的悬台接住掉下来的人。
  - 高台 1000~1300（顶 880）；左边缘内缩 50（950~1000 顶 900 台阶）；
    台阶上弱风 940~990（y 670~890，升力 104）+ 金币 965,700。
  - 高台右端风门 1320（门 1300~1340，风带 1200~1300；6 秒周期吹 3 秒，只在吹时开门）。
  - 回字上层 1340~1730（顶 880）；逆风 1360~1730（-160），按住 D 顶过去。
  - 升降台 1760~1880（垂直 ±110、速度 150、宽 120）：上层 879 ↔ 下层 1099。
  - 下层 940~1980（顶 1120）：地火 1400、史莱姆 1250、终点 990,1120（向左）。
- **数据**：金币 6；怪 1；检查点 0；死亡区 -200~2100。
- **为什么**：风场从“电梯”变成“要横跳的地形”；弱风是给贴边走的人的奖励
  （金币 + “原来边缘也能用”的发现）；风门教“等风”；逆风教“按住 D 顶”；
  隔板让终点必须绕一圈，把回字形路线走完。
- **注意**：第 8 关是唯一没有检查点的关；从起点掉下去要重跑整段。
  这是当前设计，长关 + 无检查点的风险需要真人试玩确认。
- **验收**：真人试玩（工具不模拟竖向风场）；重点：第一段 → 横跳 100 → 第二段、
  弱风口、风门时机、逆风、升降台。

### 第 9 关 · 分岔

- **想教**：第一次选路（真正的分岔在过桥之后：跳下去补下层，还是继续冰桥）。
- **结构**（2026-10-29 现状，坐标以 `scripts/levels/level_9.gd` 为准）：
  - 起点平台 -100~350（顶 520）；冰种 -80（平台左缘往右 20）；提示牌 330。

- **2026-10-29 的两笔改动**：
  - 结构（按设计表重排）：水池从“冰桥占位”改成真正的下沉水池（水面低于桥面、落水即复位），
    冻住后冰桥升到桥面高度；950~1400 从“冻池变成的桥”改成常驻冰面平台
    （`scripts/world/platform.gd` 新增 `slippery` + `is_slippery()`，`level_base.gd` 新增 `_add_ice_platform`）；
    水池 150→240 宽，上层平台左端 500→590；冰种 250→-80；金币挪到 700 / 880 与 500 / 1200；
    提示牌改成“水池：拿冰冻住再走 / 过桥后跳下走下层”。
  - 水池垂直尺寸：先按表做成 下沉 100 / 深 90（水面 620、水底 710、坑高 190），
    试玩后调成 下沉 80 / 深 70（水面 600、水底 670、坑高 150）。
    `water_depth` 已做成参数（`_add_freeze_pool` 第 5 个参数），下限 20；
    “下沉量 + 深度”别超过 210，否则水底会压到下层走廊玩家头顶（780 − 42 = 738）。
- **注意**：设计表把汇合 A/B 和终点写成“顶 520”，但下层 780 起跳只有 92，跳不上去；
  表里“上层进入后可落下至共同区域”说明共同区域就在下面那层，所以 A/B/终点保持 780。

  另案：想恢复真分岔可把水池右移 80（430~670），在起点平台和水池之间留 80 空隙（未采用）。

### 第 10 关 · 风车

- **想教**：竖井升降台 + 风场、上下层、钥匙门、火盆门。
- **结构**：下层 0~1200（顶 780）；竖井升降台 x=1200（宽 120、垂直行程 180、
  顶 600 ↔ 780、速度 55）；风场 1200（120 × 400，y 300~700）；
  上层 1300~1700 与 1600~1900（顶 560，重叠 100）；钥匙 1400、钥匙门 1600；
  金币房 1800 / 1850；下层 1900~2400（顶 780）；火盆 2200、门 2300；
  地火 800；史莱姆 600；检查点 1100；金币 5；终点 2400。
- **为什么**：升降台是“等平台”的竖向版；风场把玩家从升降台顶端继续托到上层；
  钥匙门 + 火盆门把“钥匙”和“火”两种开门方式放在同一关。
- **钥匙是否可选**：旧稿写“可选”，但按当前坐标，钥匙门 1600 卡在上层唯一走廊上
  （门高 160，跳不过去），钥匙实际是必经；金币房是门后奖励。

- **验收**：升降台能坐；风场能上上层；钥匙门能开；火盆门能开。

### 第 12 关 · 终章：元素城堡

- **想教**：冰 / 岩 / 火 / 风 + 地火 + 两种史莱姆的综合。
- **结构**：-100~500 → 600~1200 → 1300~2000 → 2100~2800 → 2900~3400（四个 100 坑）；
  冰种 250 + 冻池 600（450~750，冰桥填 500~600 坑）；
  岩石 900 + 石墙 1100；火种 1400 + 冰墙 1600；
  上升风场 1640~1780（y 360~780）→ 钥匙 1710,400；风区 1830；
  地火 1000（相位 0）与 2200（相位 0.5）；检查点 1500；史莱姆 1300；
  钥匙门 2900；喷火史莱姆 3050（朝左）；金币 5；终点 3200。
