# 测试记录

> 这份文件有两个用途：
> 1. 你每天花 2 分钟记 3 行，10 天后就是 **AI 使用声明** 和 **说明文档** 的素材；
> 2. 调参数时记下“改了什么 → 感觉如何”，避免改乱了回不去。

---

## 一、每日 3 行（从 D1 开始，每天一行）

格式：

```
日期：
今天做了什么 / 遇到什么问题：
AI 帮了什么、我怎么验证的：
```

示例（D1 可以照着写）：

```
日期：2026-10-21
今天做了什么：修了第 3 关移动平台，试玩三关，下载导出模板。
AI 帮了什么、我怎么验证的：AI 说平台跑到了世界原点 (0,0)；我重玩第 3 关，
渡船真的出现在坑里，能走到终点；踩按钮不再报红字。
```
